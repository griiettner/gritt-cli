# Markdown

Read [write](../SKILL.md) first for prose guidance. The calling workflow owns
the content outline and destination. Preserve its structure and user choices.

## Workflow

1. Write or update the Markdown from the supplied outline and evidence.
   Use tables for comparisons and a small Mermaid diagram when it clarifies
   relationships. Do not require a diagram for every document.
2. When an HTML companion is requested or maintained, use the same claims,
   section coverage, and sourced numbers in both. Link to the sibling HTML
   near the top only when that file exists by handoff.
3. Keep chart runtime code in HTML. Markdown retains readable data and the
   explanation needed to understand the document on its own.
4. Apply the prose workflow from `write` to the draft or changed passages.

## Verification

Check local links, remove unused template placeholders, and verify parity with
any HTML companion. Markdown-only output needs no HTML assets or links.
