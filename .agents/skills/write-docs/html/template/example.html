Plans

Phases and blockers.

Migration order

One content type per phase, cheapest first.

Phase 0 Foundation. Create the schema, seed the locale tree with Global xx. Blocked on 5 items
Phase 1 Labels. ui_content (1,019 rows) migrates into label. Low risk, high learning
Phase 2 Menu and route. Three menu models consolidate into one. Reconciliation pain expected
Phase 3 Offerings. The first content type migrates read-through. The proof
Phase n+1 Retirement. Drop superseded tables. Mostly deleting unrun code

Phase 0 is blocked on two items

  1. 1
    DDL ledger and apply service (milestone M0)
    Named as a gate by the design itself. Nothing applies its first CREATE TABLE until this exists.
  2. 2
    Schema parameterisation (milestone M1)
    Removes the three hard-codes so the engine can target the new schema.
