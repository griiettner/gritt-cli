# Polish

Read [write-docs](../SKILL.md) first. On create, run this on both files. On edit, run it only on the passages that changed.

## Sequence

1. Load [`write`](../../write/SKILL.md). Technical register: plain and specific. Do not inject first-person voice into engineering docs.
2. On a first draft, apply the rewrite to both files. On an existing HTML file, polish only the passages this turn changed. Do not rewrite the rest of the HTML.
3. Ask what still looks generated. Fix remaining tells.

Preserve claims, section set, sourced numbers, Mermaid diagrams, chart data, and existing HTML structure. Change wording, not facts.
