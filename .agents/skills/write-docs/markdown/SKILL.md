# Markdown

Read [write-docs](../SKILL.md) first. Use the same outline as the HTML file.

## Sequence

1. Write the `.md` from the shared outline.
2. Put a link to the sibling `.html` near the top.
3. Draw flows and architecture with Mermaid (`flowchart`, `sequenceDiagram`, `graph`).
4. Use tables for side-by-side comparisons when there is no chart-worthy numeric series.
5. Stop. Chart mounts stay in the HTML file, drawn by `docCharts`.

Do not invent a second narrative. Follow the parent outline for this kind. Do not pad with sections that kind must skip.
