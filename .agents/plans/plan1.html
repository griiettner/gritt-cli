Summary

Gritt is an open-source Rust application for running AI coding agents from one place.

The first release targets macOS, Windows, and Linux. Gritt supports native provider sessions and supervised connectors for installed agents. Both paths share events, sessions, and the terminal interface.

Provider boundary

Adapters hide wire formats and provider details from the control plane.

Requests route by configured provider profile, never by guessing from a model name. Each adapter sends prompts, streams provider-neutral events, submits tool results, restores continuation state, reports capabilities, and returns internal error kinds.

One event model

Text, reasoning summaries, tool calls, results, approvals, usage, status, errors, and completion have the same shape for native and connector sessions.

Each wire envelope has its own normalizer and tool-schema generator. Provider-specific fields stay in optional diagnostic metadata.

Harness and execution

Planning is conversation. Coding reads, writes, and runs approved tools.

Print mode is scriptable. REPL mode adds history and continuation. Full-screen mode adds the streamed transcript, tool activity, multiline input, status, approvals, diff review, cancellation, command palette, and task views.

The native policy engine evaluates every tool call as allow, ask, or deny. It matches tool names and resources with workspace-aware wildcard rules. Native tools are workspace-bounded file read, file write, and shell execution. Child processes are tracked so cancellation can stop them.

Sessions and phases

Planning is conversational. Coding is the tool-using execution phase, and both remain in one session.

Native and connector sessions emit the same provider-neutral events for text, reasoning summaries, tool calls, results, approvals, usage, status, errors, and completion. Sessions are named, listable, resumable, removable, and owned by Gritt. Adapter continuation state stays behind the session interface.

Configuration and security

Configuration is explicit, layered, and safe to inspect.

Precedence is command-line flags, project config, user config, environment variables, then built-in defaults. Profiles hold protocol, base URL, and key variable name, but never secret values. Keys come from the OS credential store first and the named environment variable second. Structured logs are content-free by default; explicit content logging retains seven days.

Connectors

Gritt supervises external agents without taking away their authority.

Connectors launch installed agents through documented machine-readable interfaces where available. PTY is the fallback, and terminal scraping is the last resort. Gritt supervises processes, relays approvals, records decisions, and reports each connector's capabilities, version, and auth state. Missing or outdated connectors never break the native path.

Risks

The plan keeps compatibility and safety risks visible from the first phase.

Provider drift is controlled with recorded fixtures, adapter contract tests, and capability checks. Connector fragility is isolated with documented protocols, version checks, health checks, and cancellation. Key handling keeps secrets out of files and logs. Cross-platform packaging and signing start in Phase 0. Phase order limits harness and connector scope creep.
