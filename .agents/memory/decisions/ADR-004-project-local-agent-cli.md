# ADR-004: Project-local agent CLI

## Decision

Repository maintenance for local memory, tickets, and skill adapters runs
through one Rust binary, `gritt-agent`, whose crate lives at `.agents/cli/`.
The crate is its own Cargo workspace root and is not a member of the product
workspace.

Local memory is a SQLite file at `.agents/brain/data/agent-memory.db`. SQLite
FTS5 is the retrieval baseline and the only retrieval path. The MCP server
`gritt-local-memory` is `gritt-agent memory serve` over stdio, declared in
`.mcp.json` as the release binary path. Each checkout builds it once with
`cargo build --release --manifest-path .agents/cli/Cargo.toml`.

Node stays only for the scripts that have no Rust replacement yet. Those
scripts call `gritt-agent` for index and adapter sync rather than carrying
their own copies of that logic.

## Rationale

- The Node memory tools needed packages that were never declared in this
  checkout, so agents could not query local memory at all.
- The product is Rust. One toolchain for product and tooling keeps a clean
  checkout buildable with nothing else installed.
- A binary path in `.mcp.json` works when the MCP host does not have
  `~/.cargo/bin` on its PATH, which is common for desktop applications. The
  cost is a documented one-time build.
- Keeping the crate outside the product workspace means product crate rules
  (no I/O in core, provider neutrality) do not have to bend for tooling.
- FTS5 alone satisfies the retrieval contract in `.agents/brain/`. Embeddings
  and reranking remain future options behind the reserved vector columns.

## Consequences

- Generated indexes and stubs regenerate with `gritt-agent ticket sync` and
  `gritt-agent skill sync`. Validation is `gritt-agent ticket validate`.
- `.agents/cli/target/` and `.agents/brain/data/` are ignored by Git.
- The generated stub marker reads `GENERATED BY gritt-agent skill sync`.
- Replacing a remaining Node script means adding a `gritt-agent` subcommand,
  proving parity against the fixtures under `.agents/cli/tests/`, and only
  then deleting the script.
- Memory search returns citations as `path:start-end` line ranges. Tools that
  add retrieval later must keep FTS5 working without any provider.
